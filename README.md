<div align="center">

<a href="https://smart-attendance-system-orpin-five.vercel.app/">
<img width="100%" src="https://image.thum.io/get/width/1000/crop/600/https://smart-attendance-system-orpin-five.vercel.app/" alt="Smart Attendance application preview"/>

</div>

A location-aware attendance system using dynamic QR verification and server-side validation.

| Feature | Implementation |
|---|---|
| QR refresh interval | 30 seconds |
| Token generation | UUID-based verification |
| Location validation | Haversine distance calculation |
| Attendance monitoring | Live check-in visibility |
| Proxy mitigation | Token rotation + location checks |

**Verification flow**

`Rotating QR → Token Validation → GPS Geofence → Attendance Record`
